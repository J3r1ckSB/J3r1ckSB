## What I have built

- **Hey Eva**: a real-time voice AI companion, live on the [App Store](https://apps.apple.com/co/app/hey-eva/id6769547452) and [Google Play](https://play.google.com/store/apps/details?id=com.gtia.eva), with 209 users and 2,600+ conversations as of October 2026. I built the Flutter app with its native Swift and Kotlin layers and a C++ echo-cancellation layer. I also built the Python (FastAPI) voice server on Google Cloud Run with the Gemini Live API.
- **Delamark**: a clothing brand and its online store, from the first commit to live in 17 hours and 27 minutes. I directed 496 agents across 52 workflows; they built payments with Wompi, shipping with Envia, the order emails, an admin panel and a 20-tool MCP server to run the store from Claude. It is online in test mode at [delamarkstore.com](https://delamarkstore.com).
- **D'Lamark Productions**: event ticketing that has sold real tickets at [dlamark.com](https://dlamark.com) since October 2026, with guest checkout, QR tickets in Apple and Google Wallet, and a door scanner that works offline.
- **CAA Suite**: a desktop app (Electron, React, TypeScript, Supabase) where AI agents take social-media videos from script to publishing. It has 25 packages and custom MCP servers that expose 60 tools. Its video engine produced Delamark's product videos.
- **KVRA Orquesta**: an agent harness on Claude Code that our team uses daily. It coordinates agents, runs independent reviewers and scripted gates, and a benchmark decides which model does each job. In the two projects built with its plan-first method, 120 of 124 pieces passed their check on the first try.
- **[uccontigo.edu.co](https://uccontigo.edu.co)**: the new website of a university in Barranquilla, live and edited by its own staff.
- **[bondi-wellness.pages.dev](https://bondi-wellness.pages.dev)**: a hotel site in Spanish and English that plays like a film as you scroll, built in one day with my plan-first method.
- **Toro Estates Group**: the site of a real estate brokerage in Florida and Puerto Rico, where the home page goes from Miami at night to morning as you scroll. Not yet launched; there is an unconnected [preview](https://toro-estates-vista-previa.pages.dev).
